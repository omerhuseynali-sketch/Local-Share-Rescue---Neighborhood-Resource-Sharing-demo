# Local-Share-Rescue---Neighborhood-Resource-Sharing-demo
A website demo for sharing and rescueing neighborhood requests# Local Share & Rescue

A lightweight, responsive web application for real-time neighborhood resource sharing and emergency supply coordination. Neighbors can publish supplies, track urgent needs, and reserve active items.

## 🚀 Features

- **Dynamic Publishing:** Post items with categories (Food, Tools, Clothing), urgency tags, donor contacts, and photos.
- **Auto-Sorting Feed:** Newest listings immediately appear at the top of the feed using `unshift()`.
- **Live Reservation System:** Instantly toggle item status between "Reserve Item" and "Cancel reservation."
- **Expiration Tracking:** Automatically tracks remaining minutes left on posts and greys out expired items.
- **Sticky Desktop Layout:** Split-screen layout keeping the submission form locked in place while scrolling posts.

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5
- **Styling:** Custom CSS3 (CSS Grid, Flexbox, Media Queries)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation)

## 📂 Project Structure

```text
├── index.html        # App layout, structure, and forms
├── style.css         # Modern styling and responsive desktop grid layouts
└── app.js            # Live component rendering, card filtering, and event logic
```

## 💻 Setup & Installation

1. Clone or download this project folder to your local machine.
2. Open the directory in **VS Code**.
3. Right-click `index.html` and select **Open with Live Server** (or simply double-click `index.html` to open it directly in Google Chrome, Edge, or Firefox).
